本檔為 `sgud/rule/rulebook.md` 之分冊(2026-10-22 主控依使用者指示自原 312KB 之帳本依類型分拆;節之標題與內容不變).索引與其他分冊見 `rulebook.md`.

## 專案特有機制

- 統計頁確定性資料: `settings.staEventMock=true`(`genMockStaEvent` 固定 48 桶 sin 計數, `genMockStaEventTable` 固定表)經 `restartBackend(genTempSettings({ staEventMock: true }))`; `e2e-init` E2E-003 亦用.
- 端到端不變式: `getResolvedActiveTargets(page, userId)` 打 `getPermUserInfor?token={token-for-application}` 取解析後權限樹(isActive 之 target 排序), 驗「外部應用實際查到的結果」.
- server 注入語系初始畫面: `e2e-init`(`page.route('**/api/**')` 懸置; 打後端 dist).
- `api-doubleclick`(2026-09-28 由 `e2e-doubleclick` 改名, 見 spec/設計要點與取捨.md ADR-017 Update)為 **API-level**(無 UI), 2026-09-29 依 ADR-025 改寫: **DC-01～04** 為**兩位不同操作者**(`sys` → `id-for-admin`、`{token-for-application}` → `id-for-application`)`Promise.allSettled` 並行 2 次同表 `updateXxx`, 契約為**兩次皆 success**、DB 終態＝其中一份完整快照、無 lost-update(原以同一 `sys` 並行; ADR-025 起同一操作者之第 2 次為 `saveInProgress`, 故改兩位操作者保留 ADR-012 契約); 第二位操作者沿用既有測試權杖, 不新增權杖——資料通道須其 id 於 perm users 表(mappingBy 預設 `id`)且 `isAdmin='y'` / `isActive='y'`, 故 before 以 `sys` 之 `updateUsers` 插入該列(`from='apiDoubleclick'`), users 之案例基底＝base seed＋該列, after 以 base seed 還原並以 `delAll({from})` 兜底(殘留會使 `api-verifyConn-auth`「`{token-for-application}` 走 client 通道應拒」失敗). **DC-05／06**(四表各一): 同一操作者(`sys`)送同一包含 `_isNew` 新列——並行 → 恰 1 成功 1 拒絕且拒絕 key ∈ {`saveInProgress`, `saveNewRowExists`}; 依序 → 第 2 次 `saveNewRowExists`; 皆斷言新列只 1 筆、建立者＝`id-for-admin`、建立時間非佔位字、`_isNew` 不入庫. 改名後不再匹配 `run-e2e-isolated.mjs` 之 `e2e-*.test.mjs` pattern、**不再納入逐檔隔離 runner**, 改與其餘 `api-*`/`unit-*` 共用同一後端由 `npm test` 涵蓋(理由與確認見該檔註解)。
- **echarts 圖例(統計頁事件發生頻率圖)之讀取與點擊一律用 setup 共用 helper**(2026-09-24 收斂自 e2e-stainfor 檔內 `EVAL_LEGEND_INFO`): `readStaLegend` / `waitStaLegendSettled` / `assertStaLegendLayout`(不變條件: 圖寬＝容器寬、每事件皆有圖例、圖例頂 ≤ 10、圖上類型＝元件判定、文字底 ≤ 57、捲動式單列) / `clickStaLegendItem` / `clickStaLegendPager`; 由 zrender `getDisplayList(true)` 取視窗座標後 `page.mouse.click`(L2). 三條規則: ①捲動式時窗外項目仍在顯示列表(被 clipPath 裁掉), 只點 `inWindow` 者, 否則點到翻頁鈕或空白; ②翻頁鈕以元素名 `pagePrev`/`pageNext` 定位, 頁次讀 `parent.name==='pageText'` 之 TSpan(`pageText` 為 ZRText, 本身不在顯示列表, 以 `el.name==='pageText'` 找永遠為 null——2026-09-24 驗收探測即踩到, 使「縮放後頁次保留」一條變成空驗), **不得**以 `/\d+\/\d+/` 比對文字找頁次(會誤中 x 軸 `01/02`); ③一行放得下時翻頁鈕仍在但 `invisible`, 以此判是否顯示. 盤點指令: `git grep -n "getDisplayList" -- test` 與 Grep 未追蹤之 `test/unit-legendFit.test.mjs` — 只應出現在 `test/tools/e2e-setup.mjs`(helper)與 `test/unit-legendFit.test.mjs`(量測器對照可見圖, 不點擊).

- **R-PKG-01 會被打包之模組不得於頂層宣告 `__filename`/`__dirname`, 以模組位置定位之檔案於首次使用時解析並快取**: rollup 之 umd 墊片把 `import.meta.url` 換成 `require('url').pathToFileURL(__filename).href`, 其避讓名單不含 `__filename`——同一 bundle 內任一模組頂層宣告之 `__filename`(改名後)都會被墊片綁到, 載入即 TDZ `ReferenceError: Cannot access '<名>' before initialization`; 解析失敗時 runWorker 以該 Error reject(不在載入時拋); 保留 `fpWk` 注入點. 前提: `.npmignore` 未排除 `server/`(已安裝時 worker 檔存在; 若改動須同步改本規則). 站點全集(2026-10-14 盤點 `rg -n "__filename|__dirname|import\.meta|fileURLToPath|new URL\(|new Worker\(|createRequire" server src srv.mjs g_*.mjs`): 只有 `server/staLogs/staLogsCore.callWorker.mjs`(原 :8-11 頂層 `__filename`／`__dirname`／`fpWkDefault`);
