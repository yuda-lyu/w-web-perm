# 規則帳本:權杖、寫入路徑與使用端物件

本檔為 `sgud/rule/rulebook.md` 之分冊(2026-10-22 主控依使用者指示自原 312KB 之帳本依類型分拆;節之標題與內容不變).索引與其他分冊見 `rulebook.md`.

## 權杖不外洩(2026-09-25, ADR-023; 對應 w-web-sso ADR-068 之 W / M / K 契約)

通道軸: C1 HTTP 回應 / C2 srLog 欄位值 / C3 自家 console(stdout) / C4 下游 error 事件經 srv.mjs 印出 / 瀏覽器 Referer. 權杖所在: query `token`、`Authorization`、`Referer`、RPC 本體 `__sysToken__`、SDK 代入值、例外之 message. 以下三條規則之站點全集皆由盤點指令自碼取得, 不由需求文字推導.

- **R-TOK-1 注入函數只經 `wrapInjected`**: `WWebPerm` 建構參數 `getUserByToken` / `verifyClientUser` / `verifyAppUser` 於 `let srLog = srLogInit(opt)` 之後、WServOrm 建構之前各以 `x = wrapInjected(x, { failValue, onFail })` **取代一次**(行號以盤點指令重取), 之後函數內只能取得包裝版(2026-10-14 ADR-026: 原第四個注入函數 `opt.getUserById` 隨 w-serv-orm 1.1.9 移除而刪除, 給值即於建構時拋錯, 見下〈寫入路徑與資料通道〉R-ORM-03); 包裝前只允許函數簽名與 `isfun` / `'invalid x'` 參數檢查. 失敗值: getUserByToken → `null`(≡ 查無), verify* → `false`(≡ 無權限); `onFail` 記 `srLog.warn({ event: 'inject-<函數名>-fail', ...describeUpstream(err) })`, 且只收到 `describeUpstream` 之結果(白名單 key, 或 `upstreamType` + 名稱形狀之 `upstreamName`), 收不到原文. 站點全集(呼叫包裝版; 2026-09-25 共 5 處, 皆已套): `getTokenUser`(getUserByToken)、`getAndVerifyClientUser`(verifyClientUser)、`getAndVerifyAppUser`(getUserByToken、verifyAppUser)、資料通道 `getUserIdByToken`(getUserByToken). 盤點指令: `rg -n "\b(getUserByToken|verifyClientUser|verifyAppUser)\s*\(" server/WWebPerm.mjs`——略過註解行後, 每個命中行號須大於包裝指派行(2026-09-25 實得 408 / 467 / 490 / 505 / 1114, 包裝指派 290-292); 另 `rg -n "=\s*(getUserByToken|verifyClientUser|verifyAppUser)\s*($|[,;)])" server/WWebPerm.mjs` 須無命中(不得另存原始參數之別名; 包裝指派之右側為 `wrapInjected(…)` 故不命中). 自動化: `unit-wrapInjected` WRAP-SITE-001/002. 新增注入函數參數時比照包裝, 並加入該測試之 `NAMES`.
- **R-TOK-2 印權杖只經 `maskLog`**: console 與 srLog 之引數含權杖類值(`token` / `tokenSelf` / `authorization` / `req.query` / `headers` / `referer`)者一律經 `server/maskLog.mjs` 之 `maskTok` / `maskQuery` / `maskUrl`; srLog 不新增權杖欄位, 記錄上游錯誤一律經 `describeUpstream` 或自家 key. 站點全集(2026-09-25, 皆已套): `WWebPerm.mjs` console 22 處(getTokenUser 1、getAndVerifyAppUser 1、`/api/getUserByToken` 3、`/api/getPerm` 5、`/api/getPermUserInfor` 5、`/syncAndReplaceTabs` 5、verifyConn `authorization` 1、getUserIdByToken 1); verifyConn 之 srLog `referer` 1 處(`maskUrl`); `srv.mjs` 之 `'invalid token'` 與 JSDoc / README 範例不印值. 盤點指令: `rg -n "console\.(log|error|warn|info)\(.*(\b(token|tokenSelf|authorization|headers|referer)\b|req\.query|get\(req, 'query'\))" server/ srv.mjs README.md`——命中行之權杖類引數須包在 `maskTok(` / `maskQuery(` / `maskUrl(` 內(僅出現在字串標籤內者如 `'[API]… invalid token'`、以 `//` 註解掉之既有除錯行不算; 2026-09-25 實得 22 處皆已包、其餘命中皆屬這兩類); srLog 欄位值來源另以 `rg -n "srLog\.(info|warn|error)\(" server/WWebPerm.mjs` 逐一追到變數之賦值(ADR-016 Update 之教訓: 只看欄位名會漏 referer 與上游 msg). 自動化: `unit-maskLog` SITE-001~003(判準實作 `test/tools/srcScan.mjs`: 去掉 mask 呼叫與字串字面值後仍含權杖類識別字即違規; 跨行 console 呼叫報為無法解析而非略過); srLog 動態面: `api-tokenSafety` TS-003(讀本次後端 srLog, 以哨兵事件等待落檔).
- **R-TOK-3 SDK 代入與錯誤不帶權杖**: `src/getPerm.mjs` / `src/getPermUserInfor.mjs` 之佔位符代入一律 `split(佔位符).join(encodeURIComponent(值))`, 不用 `replaceAll`(取代字串解讀 `` $` `` 等樣式); `getPermUserInfor` 佔位符缺一即拒; 部署方回呼 `funConvertPerm` 之拋錯 / reject 一律轉 `noUserDataAfterConvert`; `src/fetchJson.mjs` 之 reject `message` 只含 `err.name`(+代碼形狀之 `cause.code` / `code`)或 `HTTP <status>`. 盤點指令: `rg -n "replaceAll|\.replace\(" src/getPerm.mjs src/getPermUserInfor.mjs src/perm.mjs server/provideTabs.mjs`(代入處不得出現; 2026-09-25 命中僅兩行說明註解); `rg -n "\.message" src/*.mjs server/provideTabs.mjs`(不得把例外 message 帶出; 2026-09-25 無命中). 自動化: `unit-sdk-tokenSafety` SDK-001~006.
- **與 w-web-sso 之同步點**: `server/wrapInjected.mjs` 之 `keysUpstream` = sso 對外 helper K 契約之 14 個 key(`unit-wrapInjected` WRAP-004 釘住清單); `server/maskLog.mjs` 之格式 = sso `server/srLog.mjs` 之 `maskToken` 與 `src/maskUrl.mjs`(`unit-maskLog` MASK-001 為四 repo 同一組測資; 非 http(s) 網址只回 protocol 亦同 sso). sso 端增減 key 或改遮罩格式時, 本專案同步修改並跑這兩支測試.
- **測試權杖守門**: `{token-for-reject}` / `{token-for-verify-throw}` 只在 `process.env.NODE_ENV !== 'production'` 生效(srv.mjs); 合成秘密一律 `SYNTH-*`, 不得使用任何真實或回報方提供之權杖片段.
- **C3 之實測**(非常設): harness 之 `spawnSrv` 丟棄後端 stdout, api 層無法斷言 console; 2026-09-25 以隔離後端(真 srv.mjs, 另埠、另 cwd / db / logs)探測, 修正前 stdout 含 5 種合成秘密(陣列 token、`authorization`、error 事件印出之上游原文)、修正後 0. 常設守護為 SITE-* 靜態不變式.
