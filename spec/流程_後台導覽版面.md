# 後台導覽版面流程

## 觸發

管理員登入後台後，畫面由左側導覽區與右側內容區組成（`LayoutContent.vue`）。導覽區列出五個頁籤（`mmStaInfor` / `mmTargets` / `mmPemis` / `mmGrups` / `mmUsers`），預設停在「統計資訊」（`menuKey` 初值 `mmStaInfor`，`LayoutContent.vue:168`）。導覽區右上角有「隱藏選單」圓鈕（`mdiArrowLeftBoldHexagonOutline`，`LayoutContent.vue:44-61`，僅 `drawer` 為真時渲染）；點擊後導覽區收合，內容區左上角改出現「顯示選單」圓鈕（`mdiArrowRightBoldHexagonOutline`，`LayoutContent.vue:100-117`，僅 `drawer` 為假時渲染），點擊即恢復導覽區。兩顆圓鈕互斥，同一時間只有一顆存在。

`drawer` 狀態以 prop 傳入五個內容頁（`LayoutContent.vue:72-95`）：收合時各頁標題區加左側內距，讓出「顯示選單」圓鈕所佔位置——四個資料頁於標題列 padding 由 `5px` 改 `5px 5px 5px 20px`（如 `LayoutContentUsers.vue:17`），統計頁於標題區塊加 `padding-left:20px`（`LayoutContentStaInfor.vue:18`）。本文件只涵蓋導覽區收合／恢復與各頁標題讓位；各頁內容之瀏覽與編輯屬各頁流程文件。

## 重要流程

本流程於 e2e-layout 驗證。統計頁為預設頁且其圖表資料隨時間變動，故後端以統計虛擬數據模式（`staEventMock`）啟動，使統計頁截圖為確定性內容（同 e2e-stainfor）。eng / cht 各一輪。視覺項每步兩張：點擊前框住要點的圓鈕，點擊後框住有反應的元素；紅框（#f26 / 5px）以截圖後疊圖方式標注。標準圖檔名前綴 `test/pics/layout/layout-{eng,cht}-`。

- **E2E-001**
  - title: 隱藏選單後標題讓位於顯示選單圓鈕
  - description: 管理員在後台任一頁點擊導覽區右上角的「隱藏選單」圓鈕後，左側導覽區收合、內容區向左延展，內容區左上角出現「顯示選單」圓鈕，而頁面標題向右讓位，不與該圓鈕重疊。以預設的「統計資訊」頁為例：收合前標題緊接導覽區右側，收合後標題左緣位於圓鈕右側，兩者之間留有空隙；「標的」「權限」「權限群組」「使用者」四頁的標題列亦同樣讓位。適合需要較寬內容區（如表格欄位較多）時使用；此操作只影響版面，不寫入任何資料。
  - flow:
    - 測試資料：後端以統計虛擬數據模式啟動（統計頁圖表確定性）；登入身分 `sys`（管理者，見 `spec/設計要點與取捨.md` 帳號矩陣）；不需 DB 種子變體。
    - 操作：登入進入後台（停在「統計資訊」頁，等圖表渲染）→ 點擊導覽區右上角「隱藏選單」圓鈕 → 等導覽區收合完成（「顯示選單」圓鈕出現、導覽面板不再顯示、內容區位置不再變動）。
    - 驗證：
      1. 語意（統計頁）：「顯示選單」圓鈕存在且「隱藏選單」圓鈕消失；統計頁標題「統計資訊」左緣 ≥ 圓鈕右緣（實測 2026-09-14，視窗 1440×900：圓鈕 x=5 寬 24 → 右緣 29；標題左緣由收合前 230 變為 50，間距 21px）。
      2. 語意（其餘四頁）：逐頁「顯示選單 → 點該頁籤 → 隱藏選單」後量測，各頁標題左緣 ≥ 圓鈕右緣（實測四頁標題左緣皆由 269 變為 84，間距 55px）。
      3. 視覺：`layout-{lang}-E2E-001-1-click-hide.png`（點擊前，框住「隱藏選單」整顆圓鈕）→ `layout-{lang}-E2E-001-2-hidden.png`（點擊後，框住統計頁標題「統計資訊」整行文字；此時「顯示選單」圓鈕位於其左側，不重疊）。
    - 雙語：eng / cht 各一輪（cht 以語系切換後再操作）。
    - 清理：`drawer` 為前端記憶體狀態，關閉瀏覽器即復原；測試後還原後端為預設（非虛擬數據）設定，並刪除臨時 settings 檔（`test/_tmp/`）。
    - 備註：對稱案例為 E2E-002（恢復導覽）。四頁讓位量測之標題元素取「內容區內文字恰為頁籤名、字級最大者」（排除導覽區同名項）；「隱藏選單」「顯示選單」圓鈕無 tooltip（`_tooltip` 已停用，`LayoutContent.vue:56,112`），以 mdi path 定位。收合／展開之就緒訊號採使用者可觀察幾何（目標圓鈕出現 + 導覽面板 `[ev-stable]` 與內容區 rect 連續取樣不變；展開態面板 x=0、寬 200，收合態面板 `display:none`），不採 WDrawer 內部 `[state]`（w-component-vue 2.5.13 於負載高時偶發停在 `hiding` / `opening`，2.5.14 已修，見〈已知落差〉；幾何訊號為使用者可觀察，故沿用）。

## 規則摘要

- **互斥圓鈕**：「隱藏選單」與「顯示選單」由同一 `drawer` 布林決定，永遠只渲染其中一顆（`LayoutContent.vue:46,102`）。
- **讓位為各頁各自負責**：`drawer` 以 prop 傳入五頁，各頁自行在標題區加左內距；新增內容頁時須比照，否則收合後標題會被「顯示選單」圓鈕壓住（本流程 E2E-001 之語意項逐頁量測即為此守門）。
- **就緒訊號**：收合／展開為 WDrawer 平移動畫（300ms），以使用者可觀察幾何為準——目標圓鈕出現、導覽面板 `[ev-stable]` 與內容區 rect 連續取樣不變（展開 x=0 寬 200；收合 `display:none`），不以固定等待時間判定；WDrawer 內部 `[state]` 標記於 w-component-vue 2.5.13 偶發卡在 `hiding`/`opening`（2.5.14 已修，見〈已知落差〉），本流程不以其為判準。
- **統計頁確定性**：統計頁為預設頁，其圖表資料隨 log 變動，截圖須在 `staEventMock` 模式下進行（同 e2e-stainfor）。

## 已知落差

- **已修復（附修復紀錄）** 2026-09-14：WDrawer 根節點 `[state]` 於收合／展開後偶發停在 `hiding` / `opening` 達 200 秒（w-component-vue 2.5.13 `WDrawer.vue:688,740` 之 `waitFun` 兜底 800×250ms），視覺於 300ms 內正常落定、使用者看不出；根因為 wsemi 1.8.92 `domIsStable.mjs` core() 丟棄 await 前觀察到的進行中動畫，高負載下 transition 之 pending 期超過 100ms 時整輪誤判穩定，而 `v-domstable` 只在翻轉時 emit、WDrawer 又依賴該 emit。後果：依賴 `[state]` 之 e2e 就緒訊號（`test/tools/e2e-setup.mjs` `waitDrawerReady`）每張多等 10 秒才放行。修復：wsemi 1.8.94 `domIsStable.mjs` 改為 await 前動畫數 + await 後再比 rect 且只計 running 之有限動畫；w-component-vue 2.5.14 `WDrawer.vue` 以 `transitionend` / `transitioncancel` 為主要訊號、指令回報為輔（`settleState`），兜底縮為動畫時長 + 1 秒。同日以 8 輪截圖後收合驗證 0 卡住、`state` 於 0.5 秒內落定。本流程仍以幾何為就緒訊號（使用者可觀察），`[state]` 於修復後亦可靠。

- **已修復（附修復紀錄）** 2026-09-14：統計頁未為「顯示選單」圓鈕讓位——`LayoutContentStaInfor.vue` 已宣告 `drawer` prop 但模板未使用，收合後圓鈕（x=−1..35, y=58..94）與標題「統計資訊」墨跡（x=30..126, y=80..112）重疊 5×14px（部署方 `rddmanager_2_perm` 於 1600×900 實測，證據 `rddmanager_2_perm/spec/evidence/bckfix_C_probeDrawer.log`；四個資料頁已正確讓位）。修復：標題區塊加 `:style="drawer ? '' : 'padding-left:20px;'"`（`LayoutContentStaInfor.vue:18`，對稱 `w-web-sso` 1.0.74 同名元件），修復後間距 21px（本流程 E2E-001 語意項 1）。之前未被 e2e 抓到的原因：既有 e2e 無導覽收合案例、且審計軸只列四個資料頁而漏了第五個內容頁，本流程即為補此缺口而立。
